## Security/structural guarantees and their proof location

| Guarantee | Verified by |
|---|---|
| LPU never holds `sk_HE` | `fairlend.crypto.ckks.context_can_decrypt`, checked at construction in `LoanProcessingUnit.__init__`/`comp_sim`/`compute_encrypted_audit`; structurally tested in `tests/scientific/test_key_separation.py`, `tests/scientific/test_key_ownership.py` |
| No per-record decryption in the production path | `tests/scientific/test_encrypted_aggregation.py`, `tests/scientific/test_final_audit_boundary.py` (monkeypatch-based: fails if `.decrypt()` is ever called on the LPU path) |
| `EncryptedAuditPacket` carries no per-record field | `tests/scientific/test_encrypted_aggregation_privacy.py` (exhaustive field enumeration) |
| No secret material in benchmark result files | `tests/unit/test_benchmarks.py::test_measure_len_only_*`, `test_run_benchmarks_script_never_writes_a_raw_secret_context_field` |
| Delta*/tau selected from VALIDATION only, never TEST | `tests/scientific/test_matching_fidelity.py`, `tests/unit/test_threshold_policies.py::test_all_policy_functions_have_no_test_data_parameter` |
| No train/validation leakage into final audit population | `tests/scientific/test_no_leakage.py`, `fairlend.audit.aggregation.build_audit_frame`'s own leakage assertion |
| Synthetic label never used as a credit-model feature | `tests/scientific/test_gender_exclusion.py` |
| Primary-policy provenance internally consistent across LR/RF/matching artifacts | `tests/unit/test_primary_policy.py` (provenance mismatch, aggregate-reconstruction mismatch, data-scope mismatch, distinct-realisation checks) |
| Sensitivity sweep never refits models / never changes frozen decisions | `tests/unit/test_alpha_seed_sensitivity.py::test_assert_frozen_predictions_unchanged_*`, `test_module_never_imports_credit_models` |

## Reproduction commands (in dependency order)

1. `evaluation/prepare_lendingclub.py` → `evaluation/split_dataset.py` → `evaluation/generate_synthetic_gender.py`
2. `evaluation/train_credit_models.py` → `evaluation/run_plaintext_audit.py` / `run_threshold_policy_sensitivity.py` / `run_proxy_diagnostic.py`
3. `evaluation/run_matching_fidelity.py` (Stage 1)
4. `evaluation/run_primary_policy_encrypted_audit.py --model logistic_regression ...` (Stage 2), then `--model random_forest ...` (Stage 3)
5. `evaluation/build_primary_policy_results.py` (Stage 4 consolidation — reads Stages 1–3's artifacts only, no cryptography)
6. `evaluation/run_alpha1_seed_sensitivity.py` (Phase 10 — plaintext only)
7. `evaluation/run_benchmarks.py` (Phase 11 — independent of 1–6, only needs the crypto/role modules)

Every script above takes `--dataset-sha256`/`--data-scope` (or reads the fixed CKKS config) explicitly — none silently substitutes a different dataset, fixture, or policy.
